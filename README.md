# AI playbooks

Prompts and guides from my **I Asked an Agent** series. Practical things you can ask an AI agent to build or do for your own use.

## Photo albums

Turn photographs of old album pages into individual pictures you can browse and share. Ask an agent to build a local app with cropping, perspective correction, rotation, face detection, glare checks and saved batch progress.

[Get started](photo-albums/README.md) · [Full agent prompt](photo-albums/prompt.md)

Each playbook has a short guide for you and a complete prompt to give your agent.
